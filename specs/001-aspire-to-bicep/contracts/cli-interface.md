# CLI Interface Contract: `rad aspire convert`

**Feature**: 001-aspire-to-bicep
**Date**: 2026-02-19

## Command Signature

```
rad aspire convert <manifest-file> [--output <path>] [--force] [--application <name>]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `<manifest-file>` | Yes | Path to the Aspire manifest JSON file to convert. |

## Flags

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--output` | `-o` | `app.bicep` | Output file path for the generated Bicep file. |
| `--force` | `-f` | `false` | Overwrite the output file if it already exists. |
| `--application` | `-a` | Derived from manifest | Name of the Radius application resource. If not provided, derived from the manifest filename or first container resource name. |

## Standard Flags (inherited)

| Flag | Description |
|------|-------------|
| `--config` | Path to Radius configuration file. |
| `--output` | Output format (conflicts with `-o` above — see Note). |

**Note**: The `--output` flag for file path will use the long form `--output` / short form `-o`. If there is a conflict with the inherited output-format flag, the file path flag will be named `--out-file` instead. This will be resolved during implementation based on the existing flag namespace.

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Conversion completed successfully. |
| `1` | General error (invalid input, I/O failure, etc.). |

## Standard Output (stdout)

On success, the command prints a conversion summary:

```

Converted resources:
  ✓ cache (container.v0) → Radius.Compute/containers
  ✓ app (container.v1) → Radius.Compute/containers
  ✓ cache-password (parameter.v0, secret) → @secure() param cache_password
  ✓ cache-password-uri-encoded (annotated.string, uri) → var cache_password_uri_encoded

Warnings:
  ⚠ docker-hub: manifest error — This resource does not support generation in the manifest.
  ⚠ app (container.v1): has build configuration — build and push the image before deploying
  ⚠ frontend (container.v1): skipped — build-only artifact (build.buildOnly: true)
  ⚠ cache-password-uri-encoded (annotated.string): best-effort uriComponent() mapping — verify correctness

Generated: app.bicep (2 containers, 1 gateway, 1 param, 1 var, 2 skipped)
```

## Standard Error (stderr)

Error messages for invalid input:

```
Error: file not found: ./missing-file.json
```

```
Error: invalid JSON: unexpected end of JSON input in ./bad-manifest.json
```

```
Error: output file already exists: app.bicep (use --force to overwrite)
```

## Warning Output (stderr)

Warnings for unsupported or partially-supported resources:

```
Warning: resource "docker-hub": manifest error — This resource does not support generation in the manifest.
Warning: resource "cache-password" (parameter.v0): mapped to @secure() param cache_password
Warning: resource "cache-password-uri-encoded" (annotated.string): best-effort uriComponent() mapping — verify correctness
Warning: resource "app" (container.v1): has build configuration — ensure image is built and pushed before deploying
Warning: resource "frontend" (container.v1): skipped — build-only artifact (build.buildOnly: true)
```

## Generated Bicep File Structure

The output Bicep file follows this structure:

```bicep
// Generated by: rad aspire convert
// Source: aspire-manifest-invalid-manifest-field.json
// Date: 2026-02-20T22:24:44Z

extension radius

@description('The ID of your Radius Environment. Set automatically by the rad CLI.')
param environment string

@description('The name of the Radius Application.')
param applicationName string = 'aspire-app'

@secure()
@description('Redis password for the cache container.')
param cache_password string

@description('URI-encoded Redis password (for constructing redis:// URIs).')
var cache_password_uri_encoded = uriComponent(cache_password)

resource app 'Radius.Core/applications@2025-08-01-preview' = {
  name: applicationName
  properties: {
    environment: environment
  }
}

// ... container resources with resolved env vars, gateways ...

// Unsupported: cache-password-uri-encoded (annotated.string) — manual configuration required
// Skipped: docker-hub — manifest error: This resource does not support generation in the manifest.
// Skipped: frontend — build-only artifact (build.buildOnly: true), not a runtime container
```
